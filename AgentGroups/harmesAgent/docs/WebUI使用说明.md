# 爱马仕Lucky 使用说明（同事版）

> 给第一次访问的小伙伴看的简单上手文档。

---

## 这是什么？

**爱马仕Lucky** 是一个 AI 助手，能帮你做很多事——查资料、写文档、画图、做 PPT、读 PDF……

你有两种方式跟它聊天：

| 方式 | 适合场景 |
|---|---|
| 📱 **飞书** | 日常用，手机/电脑都行 |
| 🌐 **网页版** | 演示用，临时看会话历史 |

### 页面有啥？挨个介绍

打开后左边是导航栏，主要有这几块：

#### 💬 Chat（聊天）
直接在网页里跟 AI 对话，跟飞书一样用，但**界面更舒服**，能看到 AI 思考过程、调用了哪些工具。

#### 📚 Sessions（会话历史）
所有对话记录都在这里，可以**回看**、**继续上次的话题**、**搜索历史**。

> ⚠️ **注意**：这台机器是大家共用的，**所有人的会话都在一起**。别在这里聊隐私内容。私事去飞书私聊。

#### ⚙️ Config（配置）
查看 AI 的当前配置：用哪个模型、温度、最大 token 等。**别乱改**，改了所有人都受影响。

#### 🔑 Env（环境变量）
API Key、密码这些。**别动**，里面有钱。

#### 🛠️ Skills（技能库）
80 多个内置技能，看看 AI 都会啥：

| 类别 | 例子 |
|---|---|
| 办公 | Notion / Google Docs / 飞书 / Airtable / PPT / PDF |
| 创作 | 思维导图 / 像素画 / Excalidraw / 漫画 / 信息图 |
| 研究 | arxiv 论文 / 博客订阅 / Polymarket |
| 媒体 | YouTube 总结 / Spotify / GIF 搜索 |
| 开发 | GitHub / 调试 / 代码审查 |

聊天时不用主动选 skill，AI 会自己判断该用哪个。

#### ⏰ Cron（定时任务）
让 AI 定时干活，比如"每天早上 9 点发一份昨日新闻摘要给我"。**普通同事不用动**。

#### 📊 Analytics（统计）
看用了多少 token、调了多少次 API、各 skill 使用率。看看好玩。

#### 📜 Logs（日志）
后台运行日志，**程序员看的**，普通同事跳过。

#### 📖 Docs（文档）
Hermes 官方文档（英文）。

## 几个小贴士

### 1. 它会调工具，需要等
有些任务（搜资料、做 PPT、看 PDF）要花 10–60 秒，**不是卡了，是真在干活**。耐心等。

### 2. 它能记住上下文
同一个会话里，前面说过的内容它都记得。换个新话题建议**新开会话**（左上角"New Chat"）。

### 3. 不要让它执行危险操作
它有"终端"和"文件操作"权限，理论上能删你的文件。**不要让它跑奇怪的命令**，比如：
- ❌ "帮我把 D 盘清空"
- ❌ "运行这段脚本：[陌生代码]"

### 4. 中英文都行
它母语是英文，但中文也很流畅。

### 5. 演示完会关
这个网页版只是临时开放看看，演示结束会关掉。日常请用飞书。
