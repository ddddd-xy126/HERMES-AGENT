# Hermes-Agent 小白保姆使用教程

> 这份文档专门写给**完全不懂 Linux/命令行**的人。每一步都告诉你**点哪里、敲什么、看到什么算成功**。
>
> 写于 2026-04-28，环境：Windows 11 + WSL2 + Ubuntu 24.04 + Hermes-Agent v0.11.0
>
> 你的 Hermes 已经装好了。这份文档教你**怎么用、怎么开关、出问题怎么自救**。

---

## 0. 先认识三个家伙

打个比方：你家有一条小狗叫 Hermes，它住在你电脑里，能帮你干活。

| 角色 | 名字 | 干啥的 |
|---|---|---|
| 🐶 狗 | **Hermes Agent** | AI 大脑，读消息、想问题、调工具、回复你 |
| 🚪 门 | **Gateway** | 守在飞书门口，把飞书消息搬给 Hermes |
| 🪟 窗 | **Dashboard** | 一个网页（本机 9119 端口），可视化看 Hermes 状态 |

> 只要 **Gateway 活着** → 飞书能聊
> 只要 **Dashboard 活着** → 浏览器能开 `http://localhost:9119`

## 1. 三种使用入口（任选）

### 入口 A：飞书手机/电脑（最常用，**推荐**）

1. 打开飞书 App
2. 找到机器人「**爱马仕Lucky**」
3. 直接发消息就行：
   - 文本：「帮我查下今天北京天气」
   - 图片：直接发图，加一句「这是什么？」→ 它会识图
   - 任务：「帮我把 D 盘的 xxx 文件夹列出来」「帮我搜一下 xxx 资料」

> ⚠️ 目前**不能让它生图**（因为你的 N1nKey 没绑生图渠道，详见第 6 节）。

### 入口 B：Web Dashboard（电脑浏览器看后台）

1. 浏览器打开：**http://localhost:9119**
2. 你能看到：会话历史、配置、日志、工具状态等

### 入口 C：命令行 TUI（程序员玩法，可不学）

打开 PowerShell：
```powershell
wsl -d Ubuntu
hermes
```
直接在终端跟它对话。

## 2. **每天用之前**：先确认它活着

打开 PowerShell，复制粘贴回车：

```powershell
wsl -d Ubuntu -- bash -lc "ps -ef | grep -E 'hermes (gateway|dashboard)' | grep -v grep"
```

**看到两行**（一行 `gateway run`，一行 `dashboard`）= 一切正常 ✅
**只看到一行或没看到** = 需要启动，看第 3 节。

> 全部复制粘贴到 PowerShell 就行。`d:\webDevFrontProject\harmesAgent\` 是脚本所在目录，已经写死，不用改。

### 3.1 启动飞书机器人（Gateway）

看到 `✓ Gateway running.` = 成功，飞书可以聊了。

### 3.2 启动 Web 控制台（Dashboard）

### 3.3 重启飞书机器人（**配置改动后必做**）
```powershell
wsl -d Ubuntu -- bash /mnt/d/webDevFrontProject/AgentGroups/harmesAgent/scripts/runtime/restart-gateway.sh
```


## 5. **它没回我消息？** 三步自救法

### 第 1 步：看它还活着吗
```powershell
wsl -d Ubuntu -- bash -lc "ps -ef | grep 'hermes gateway' | grep -v grep"
```
**没输出** → Gateway 死了，跑第 3.1 启动它。
**有输出** → 进第 2 步。

### 第 2 步：看最近的错误日志
```powershell
wsl -d Ubuntu -- bash -lc "tail -40 ~/.hermes/logs/gateway.log"
```
把这个输出复制给我（或 GPT），90% 能定位问题。常见关键词：

| 看到 | 含义 | 自救 |
|---|---|---|
| `Access denied` + 飞书链接 | 飞书权限缺失 | 点链接申请，重新发布版本 |
| `Another local Hermes gateway` | 重复启动 | 跑第 3.3 重启 |
| `Unauthorized user` | 飞书用户没配对 | 看第 7 节 |
| `connection refused` / `WebSocket` | 网络问题 | 等等再试或重启 WSL |

### 第 3 步：暴力重启
```powershell
wsl -d Ubuntu -- bash /mnt/d/webDevFrontProject/AgentGroups/harmesAgent/scripts/runtime/restart-gateway.sh
```

## 6. **生图功能**：现在不能用，怎么开

### 现状
你的 N1nKey API key 只绑了 Claude 文本/识图模型，**没有任何生图渠道**。所以让 Hermes 画图它会拒绝。

### 想开通的话，三选一

#### 选项 A：N1nKey 加图像分组（推荐，体验一致）
1. 登录 N1nKey 控制台
2. 新建一把 API Key，分组里勾选包含 `gpt-image-2` / `dall-e-3` / `flux` 的分组
3. 把新 key 给我（或下面命令自己改）：

```powershell
wsl -d Ubuntu -- bash -lc "echo 'OPENAI_IMAGE_API_KEY=新的key粘这里' >> ~/.hermes/.env"
```

> 注意：Hermes 默认从 `OPENAI_API_KEY` 读 key 调生图。如果你想 Claude 用一把 key、生图用另一把，需要改 `plugins/image_gen/openai/__init__.py`，**这个有点麻烦，建议直接用同一把 key 但分组里同时含 Claude 和图像**。

#### 选项 B：用 fal.ai（速度快、模型多）
1. 去 https://fal.ai 注册，拿 `FAL_KEY`
2. 跑：
```powershell
wsl -d Ubuntu -- bash -lc "echo 'FAL_KEY=你的fal_key' >> ~/.hermes/.env && hermes plugins disable image_gen/openai"
```
3. 重启 Gateway（3.3）

#### 选项 C：用 OpenAI 官方
跟选项 A 同样的 `gpt-image-1` / `dall-e-3`，把 `OPENAI_API_KEY` 换成官方 key 即可（但这样 Claude 就用不了 N1nKey 了）。

## 7. **新增飞书用户**让别人也能跟它聊

默认只有你（`ou_fdcc37a1688444fb63b67ce654cda55f`）能用。让别人用：

1. 让他在飞书里给「爱马仕Lucky」发一条消息（任何内容）


3. 批准：
```powershell

```
4. 对方再发消息就能用了。

## 8. **改配置**怎么操作

### 主配置文件：模型、生图、各种开关
```powershell
wsl -d Ubuntu -- bash -lc "nano ~/.hermes/config.yaml"
```
改完 `Ctrl+O` 回车保存 → `Ctrl+X` 退出 → 跑 3.3 重启 Gateway。

### 密钥/环境变量：API Key、飞书 Token 等
```powershell
wsl -d Ubuntu -- bash -lc "nano ~/.hermes/.env"
```
> ⚠️ `.env` 有敏感信息，**别截图发群**。

### 当前关键配置速查

| 项目 | 文件 | 当前值 |

## 11. 安全提醒（**重要**）

1. 🔐 **API Key 别外传**。`~/.hermes/.env` 里的 `OPENAI_API_KEY`、`FEISHU_APP_SECRET` 都是钱/隐私。
2. 🔐 之前对话里的 N1nKey 已经暴露给 AI 了，**有空去 N1nKey 控制台重新生成一把**，更新到 `.env`。
3. 🔐 Ubuntu 密码也暴露了，建议改：
   ```powershell
   wsl -d Ubuntu -- passwd
   ```
4. 🚪 Dashboard 现在监听 `0.0.0.0:9119`，**同局域网别人能访问**。如果你电脑在公司/咖啡厅 Wi-Fi，建议关掉或改 `127.0.0.1`。

## 12. 卸载 / 重装

### 完全卸载 Hermes（保留 WSL）
```powershell
wsl -d Ubuntu -- bash -lc "hermes uninstall"
```

### 把 WSL 也删掉（核弹级）
```powershell
wsl --unregister Ubuntu
```
> ⚠️ **不可逆**，所有 Linux 文件都没了。

## 出问题找谁

1. 先看本文档第 5 节
2. 看 `~/.hermes/logs/` 下三个日志：`gateway.log` / `agent.log` / `errors.log`
3. 把错误日志贴给 AI 助手（Copilot/ChatGPT）

**核心心法**：90% 的问题靠"重启 Gateway + 看日志"能解决。
